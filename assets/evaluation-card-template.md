# Skill 评估卡片模板

## Markdown 卡片

```markdown
┌─────────────────────────────────────────────────────────────┐
│  📋 Skill 评估卡片                                              │
├─────────────────────────────────────────────────────────────┤
│  🎯 名称: {skill-name}                                        │
│  📁 类型: {category}                                          │
├─────────────────────────────────────────────────────────────┤
│  📊 总体评分                                                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  {score}/100  {risk-badge}                            │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│  ✅ 通过项                          ❌ 问题项                  │
│  - {passed-item-1}                 - {issue-1}            │
│  - {passed-item-2}                 - {issue-2}            │
├─────────────────────────────────────────────────────────────┤
│  🔒 安全扫描: {security-status}                              │
├─────────────────────────────────────────────────────────────┤
│  📥 安装建议: {install-recommendation}                        │
└─────────────────────────────────────────────────────────────┘
```

## 风险等级徽章

| 等级 | 徽章 | 颜色 |
|------|------|------|
| SAFE | ✅ | 绿色 |
| LOW | ✅ | 浅绿 |
| MEDIUM | ⚠️ | 黄色 |
| HIGH | ❌ | 橙色 |
| CRITICAL | 🔴 | 红色 |
